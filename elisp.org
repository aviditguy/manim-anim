* Basic terms

** Point
- Cursor ki current position
#+begin_src emacs-lisp
(point)
#+end_src

- *Point*    → Cursor ki current position *(point)*
- *Mark*     → Selection ka starting point. *(mark)* mark ki position. Mark invisible hota hai.
- *Region*   → *Point + Mark* ke beech ka area. Actual selected text.


* Region kab active hota hai?
Region tab active hota hai jab:
- mark set ho
- aur *Transient Mark Mode* enabled ho
Check:
#+begin_src emacs-lisp
(transient-mark-mode)
#+end_src
Default: ✅ ON

* Common user actions
| *Action*              | *Key*       |
|-----------------------+-------------|
| Set mark              | *C-Spc*     |
| Expand selection      | Move cursor |
| Cancel selection      | *C-g*       |
| Exchange point & mark | *C-x C-x*   |


- *(use-region-p)*          → Check if region is active, Returns *t* or *nil*
- *(region-beginning)*      → Returns start of region boundary
- *(region-end)*            → End of region boundary
- *(set-mark (point))*      → Mark set karta hai, Region active nahi karta (by default)
- *(push-mark (point) t t)* → Arguments: (push-mark position activate-region push-to-mark-ring)
- *(deactivate-mark)*       → Deactivating region, Useful jab command ke baad selection nahi chahiye

* Mark ring (history of marks)
- Emacs multiple marks yaad rakhta hai
- Navigation:
  - *C-u C-Spc*       Previous mark
  - *C-u C-u C-Spc*   Older mark

- *(buffer-string)*
  - Poore current buffer ka text string ke roop me return karta hai

- *(buffer-substring (region-beginning) (region-end))*
  - Getting region text with properties

- *(buffer-substring-no-properties (region-beginning) (region-end))*
  - Getting region text without properties (recommended)

- *(delete-region (region-beginning) (region-end))*
  - Delete region

- *(thing-at-point 'line)*
- *(thing-at-point 'word)*
- *(thing-at-point 'symbol)*
  - Returns the current line, word or symbol at point

(defun my/duplicate-line-or-region ()
  "Duplicate current line or region"
  (interactive)
  (if (use-region-p)
      ;; ---------- REGION CASE ----------
      (let ((text (buffer-substring-no-properties
		   (region-beginning)
		   (region-end))))
	(goto-char (region-end))
	(insert text))
    ;; ---------- LINE CASE ----------
    (let* ((beg  (line-beginning-position))
	   (end  (line-end-position))
	   (line (buffer-substring-no-properties beg end)))
      (goto-char end)
      (newline)
      (insert line))))
#+end_src

to region me ek samasya hai ki region deselect ho raha hai jabki hum *save-make-and-excursion* use kar rahe hai jo kehta hai:
- *point + mark* wapas lao

lekin:
- hum region ke andar buffer modify kar rahe hai *(insert text)*
- Emacs internally *deactivate-mark* trigger kar deta hai
- Result:
  - region logically restore hota hai
  - *par visually inactivate ho jata hai*

To isko fix karne ke liye hum 3 cheeze karenge:
1. Region boundaries save karo
2. Edit karo
3. Region *dubara activate* karo

Ek aur bohot important cheez hai *deactivate-mark*, ye emacs ka ek variable hai.
Kisi bhi editing command ke baad Emacs internally karta hai: *(setq deactivate-mark t)*
To hame isko bhi *nil* set karna hoga nahi to *region restore hone ke baad bhi deactivate ho jaayega*

#+begin_src emacs-lisp
(defun my/duplicate-line-or-region ()
  "Duplicate current line or region"
  (interactive)
  (if (use-region-p)
      ;; ---------- REGION CASE ----------
      (let* ((beg  (region-beginning))
	    (end   (region-end))
	    (text  (buffer-substring-no-properties beg end)))
	(goto-char end)
	(insert text)
	;; restore visible region
	(goto-char beg)
	(push-mark end t t)
	(setq deactivate-mark nil))
    ;; ---------- LINE CASE ----------
    (let* ((beg  (line-beginning-position))
	   (end  (line-end-position))
	   (line (buffer-substring-no-properties beg end)))
      (goto-char end)
      (newline)
      (insert line))))
#+end_src

(defun my/term-create ()

  (unless (my/term-buffer)

(defun my/update-theme-index ()
  (setq my/theme-state
	(plist-put my/theme-state
		   :index (mod (1+ (my/get-theme-index)) (length (my/get-themes))))))

* 📌 Function: my/shell--quotes-balanced-p

👉 Purpose
Ye function check karta hai:
- *str* ke andar *single quotes '*
- aur *double quotes "*
  
*even count me hain ya nahi*
Agar dono balanced → ~t~
Agar koi unbalanced → ~nil~

#+begin_src emacs-lisp
(defun my/shell--quotes-balanced-p (str)
  "Return t if single and double quotes are balanced in STR."
  (let ((single 0)
        (double 0))
    (cl-loop for c across str do
             (cond
              ((eq c ?') (setq single (1+ single)))
              ((eq c ?\") (setq double (1+ double)))))
    (and (= (% single 2) 0)
         (= (% double 2) 0))))

(my/shell--quotes-balanced-p "Hello World 'How are you'")
(my/shell--quotes-balanced-p "Hello 'World' How' are you")
(my/shell--quotes-balanced-p "'Hello \"World\" How' are you")
#+end_src


* 📌 Function: my/shell-last-command

👉 Purpose
Ye function cursor *(point)* ke pehle wali *LAST COMPLETE shell command* ko string ke form me return karta hai.

Iska kaam:
multiple commands me se sirf last
multiline command ko ek hi command maana
incomplete (unbalanced quotes) ko ignore karna

High-level Idea:
Cursor se peeche jaate hue newline pe newline check karo,
jaise hi quotes balanced mil jaaye → wahi last command ka start hai.

#+begin_src emacs-lisp
(defun my/shell-last-command ()
  "Return last shell command before point."
  (save-excursion
    (let ((end (point))
          (start (point))
          (done nil))
      (while (and (not done)
                  (re-search-backward "\n" nil t))
        (let ((candidate (buffer-substring-no-properties
                          (1+ (point)) end)))
          (when (my/shell--quotes-balanced-p candidate)
            (setq start (1+ (point)))
            (setq done t))))
      (string-trim
       (buffer-substring-no-properties start end)))))
#+end_src
